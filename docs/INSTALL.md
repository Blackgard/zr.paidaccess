# Установка и настройка

## Требования

- 1C-Bitrix 16+
- PHP 7.4+ (рекомендуется 8.x)
- Модуль Bitrix `main`
- Исходящий HTTPS-доступ к API T-Bank:
    - `securepay.tinkoff.ru:443` для боевого режима;
    - `rest-api-test.tinkoff.ru:443` для тестового режима.
- `allow_url_fopen = On` для HTTP-клиента Bitrix.

## Установка

1. Скопировать модуль в `local/modules/zr.paidaccess/`.
2. Открыть **Marketplace → Установленные решения → zr.paidaccess → Установить**.
3. Назначить права группам в **Настройки → Права доступа → zr.paidaccess**.
4. Открыть **Сервисы → Платёжный доступ → Настройки**.
5. Включить модуль на вкладке **Общие**.
6. Создать платёжный шлюз T-Bank и отметить **Использовать по умолчанию**.
7. Указать `Notification URL` из карточки шлюза в личном кабинете T-Bank.

## Что создаётся автоматически

- ORM-таблицы платежей, подписок, шлюзов, фонда, документов, журналов.
- Фонд по умолчанию для каждого активного сайта.
- Managed-файлы админки, компонентов, theme CSS и шаблонов.
- Обработчики событий Bitrix.
- Агенты напоминаний и синхронизации долга.
- Почтовые события модуля.

Повторный запуск установки/обновления безопасен: schema и managed-файлы обновляются идемпотентно.

## Основные вкладки настроек

| Вкладка                 | Назначение                                                       |
| ----------------------- | ---------------------------------------------------------------- |
| **Общие**               | Включение модуля                                                 |
| **Календарь оплаты**    | Период, срок оплаты, льготные дни                                |
| **Доступ к сайту**      | Группы проверки, шаблон блокировки, обязательные документы       |
| **Тариф и счёт**        | Фондовый взнос, налоги, содержание сайта, распределение списаний |
| **Процесс оплаты**      | Способ оплаты, тестовая сумма, политика дубликатов `order_id`    |
| **Тексты на сайте**     | Пользовательские сообщения                                       |
| **Email пользователям** | Письма после оплаты, ошибки, долг, напоминания                   |
| **Журнал и админ**      | Логирование и email администратора                               |

## Публичные страницы

Компоненты устанавливаются в `/local/components/zr/`.

| Компонент                  | Назначение                                 |
| -------------------------- | ------------------------------------------ |
| `zr:personal.subscription` | Личный кабинет подписки и оплата           |
| `zr:fund.wallet`           | Кошелёк фонда                              |
| `zr:document.list`         | Список опубликованных документов           |
| `zr:document.consent`      | Форма согласия с обязательными документами |
| `zr:panel`                 | Панель участника/модератора                |

Пример:

```php
<?php
$APPLICATION->IncludeComponent('zr:fund.wallet', '', [], false);
```
