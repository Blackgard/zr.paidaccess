# Фонд и ledger

## Принцип

Баланс фонда не хранится отдельным полем. Он вычисляется по движениям:

```text
баланс = сумма поступлений - сумма списаний
```

В фонд попадает только **фондовый взнос** (`FUND_AMOUNT`). Налоги и содержание сайта входят в сумму оплаты для банка, но не увеличивают баланс фонда.

## Таблицы

| Таблица                                 | Назначение                          |
| --------------------------------------- | ----------------------------------- |
| `zr_paidaccess_fund`                    | Фонды по сайтам                     |
| `zr_paidaccess_fund_movement`           | Поступления и списания              |
| `zr_paidaccess_fund_expense_allocation` | Доли участников при ручном списании |

## Типы движений

| Тип       | Значение    |
| --------- | ----------- |
| `income`  | поступление |
| `expense` | списание    |

## Источники движений

| Источник  | Когда создаётся                      |
| --------- | ------------------------------------ |
| `payment` | оплаченный взнос участника           |
| `refund`  | возврат ранее учтённого платежа      |
| `admin`   | ручная операция в админке            |
| `system`  | служебная операция через API сервиса |

## Сервис записи

Все изменения фонда выполняются через `FundMovementService`.

| Метод                   | Назначение                   |
| ----------------------- | ---------------------------- |
| `recordPaymentIncome()` | поступление от платежа       |
| `recordPaymentRefund()` | списание при возврате        |
| `recordManualIncome()`  | ручное поступление           |
| `recordExpense()`       | списание с проверкой баланса |

Тестовые платежи (`BILLING_PERIOD=GT`) в фонд не попадают.

## Распределение списаний

При ручном списании (`SOURCE=admin`, `TYPE=expense`) сумма распределяется между участниками с положительным остатком вклада.

| Опция                                   | Значение                             |
| --------------------------------------- | ------------------------------------ |
| `FUND_EXPENSE_ALLOCATION_MODE`          | `even` или `random`                  |
| `FUND_EXPENSE_RANDOM_PARTICIPANT_COUNT` | число участников для режима `random` |

Доли записываются в `zr_paidaccess_fund_expense_allocation`.

## Персональный остаток вклада

`FundContributorService::getContributorData()` возвращает:

| Поле                | Значение               |
| ------------------- | ---------------------- |
| `TOTAL_CONTRIBUTED` | сумма взносов          |
| `TOTAL_REFUNDED`    | сумма возвратов        |
| `TOTAL_ALLOCATED`   | сумма списаний с доли  |
| `NET_BALANCE`       | текущий остаток вклада |

## Админка

| Страница                                             | Назначение                      |
| ---------------------------------------------------- | ------------------------------- |
| `/bitrix/admin/zr_paidaccess_funds.php`              | список фондов                   |
| `/bitrix/admin/zr_paidaccess_fund_edit.php`          | карточка фонда и движения       |
| `/bitrix/admin/zr_paidaccess_fund_movement_edit.php` | ручное поступление или списание |
| `/bitrix/admin/zr_paidaccess_fund_expense_view.php`  | просмотр долей по списанию      |

## Публичный кошелёк

Компонент `zr:fund.wallet` показывает баланс, количество участников и историю движений.

```php
<?php
$APPLICATION->IncludeComponent('zr:fund.wallet', '', [], false);
```
