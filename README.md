# Модуль `zr.paidaccess`

Платный доступ, ежемесячные взносы, платежи T-Bank, фонд сайта и обязательные документы для **1C-Bitrix**.

| Параметр  | Значение                                                         |
| --------- | ---------------------------------------------------------------- |
| ID модуля | `zr.paidaccess`                                                  |
| Namespace | `Zr\PaidAccess\`                                                 |
| Версия    | 1.0.0 (2026-05-25)                                               |
| Платформа | 1C-Bitrix 16+, PHP 7.4+                                          |
| Лицензия  | [MIT](LICENSE) — свободное использование с сохранением копирайта |

Модуль закрывает доступ к сайту для выбранных групп пользователей при неоплаченной подписке, принимает оплату через **T-Bank**, ведёт собственные платежи и подписки, фондовый ledger, обязательные документы с версиями и согласиями, а также предоставляет админку и публичные компоненты.

Доменная модель использует собственные ORM-таблицы `zr_paidaccess_*` и не зависит от заказов Bitrix Sale.

## Возможности

- Проверка подписки и блокировка доступа для выбранных групп пользователей.
- Оплата через T-Bank: QR СБП или кнопка перехода на платёжную форму банка.
- Webhook-обработка статусов банка и автоматическое открытие доступа после подтверждения оплаты.
- Фонд сайта: поступления, возвраты, ручные списания, распределение списаний между участниками.
- Обязательные документы: версии, публикация, согласия пользователей с актуальными версиями.
- Публичные компоненты: личный кабинет подписки, кошелёк фонда, документы, панель участника/модератора.
- Административные разделы: подписчики, платежи, фонды, документы, шлюзы, журналы, утилиты.
- Логирование: события модуля, обмен с gateway, аудит действий администратора.

## Быстрый старт

1. Скопировать модуль в `local/modules/zr.paidaccess/`.
2. Установить модуль через **Marketplace → Установленные решения → zr.paidaccess → Установить**.
3. Назначить права группам: **Настройки → Права доступа → zr.paidaccess**.
4. Открыть **Сервисы → Платёжный доступ → Настройки** и включить модуль.
5. Создать платёжный шлюз T-Bank, указать ключи терминала и включить **Использовать по умолчанию**.
6. Передать `Notification URL` из карточки шлюза в настройки терминала T-Bank.
7. Настроить тариф, группы доступа, календарь оплаты, документы и публичные компоненты.

## Основная структура

```text
local/modules/zr.paidaccess/
├── admin/                      # страницы админки Bitrix
├── classes/general/            # PaidAccessCore: константы и чтение опций
├── docs/                       # документация
├── install/                    # установщик, компоненты, assets, шаблоны
├── lib/
│   ├── access/                 # проверка доступа и блокировка
│   ├── Admin/                  # сервисы административных страниц
│   ├── Document/               # документы, версии, согласия
│   ├── Fund/                   # фонд, ledger, распределение списаний
│   ├── Gateway/                # contracts, DTO, registry, providers
│   ├── payment/                # платежи, webhook, completion/cancellation
│   ├── Public/                 # namespace PublicUi: view services и presenters
│   ├── subscription/           # подписка, биллинг, агенты
│   └── tables/                 # Bitrix ORM DataManager
├── tools/                      # webhook и диагностические CLI tools
├── autoload.production.map.php
└── tests/                      # PHPUnit
```

## Внешние зависимости

| Сервис                     | Кто обращается       | Назначение                         |
| -------------------------- | -------------------- | ---------------------------------- |
| `securepay.tinkoff.ru`     | PHP-сервер           | боевой API T-Bank                  |
| `rest-api-test.tinkoff.ru` | PHP-сервер           | тестовый API T-Bank                |
| `api.qrserver.com`         | браузер пользователя | QR-изображение для режима `qr_sbp` |

Для оплаты без внешнего QR-сервиса используйте режим `PAYMENT_WIDGET_MODE=payment_button`.
